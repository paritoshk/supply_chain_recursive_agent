## Policies

- **Baseline (manual):** weekly review against a static reorder point (planned lead + safety days), orders only from the primary supplier at its current lead time, reactive expedite when cover drops under 7 days. Human time: 30 min per shortage review, 120 min per RFQ, 20 min per transfer.
- **Agent:** daily sentinel and the agent's decision tree: transfer from sister-site surplus first, else expedite an in-flight order, else RFQ the cheapest landed approved supplier that arrives before stock-out (expedited if needed). Never orders from non-qualified or BIOSECURE-flagged suppliers. Human time: 3 min per approval ping, only for decisions above USD 25,000 (or unpriced).

## Assumptions

- **demand:** daily rate x (1 + 0.25 * N(0,1)), floored at 0; identical stream for both policies
- **supplier_delays:** 15% of approved supplier links get one delay event (+14..35 d for 21..45 d), hitting new and in-flight orders; hero incumbent lead slipped 42 -> 70 d
- **prices:** list price from the hidden persona profile (no negotiation savings assumed for either policy)
- **baseline:** weekly review vs static ROP, primary supplier only, reactive expedite when < 7 d cover
- **agent:** daily sentinel; transfer from sister-site surplus -> expedite in-flight -> RFQ best landed approved option; never non-qualified
- **human_minutes:** {"shortage_review":30,"rfq":120,"transfer":20,"approval_ping":3}
- **authority_threshold_usd:** 25000
